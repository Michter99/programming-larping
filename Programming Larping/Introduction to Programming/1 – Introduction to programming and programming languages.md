### What is a Computer Program?
A computer is a general-purpose machine that performs tasks based on a specific set of instructions, known as a program. These can range from _system programs_ (managing hardware) to _application programs_ (user tasks like web browsing).
### Binary Language
Computers operate using _binary_ (a system of 0s and 1s) because it is easily represented by electrical signals in hardware. These represent bits, where each bit has two possible states.
### How CPUs Execute Instructions
The _Central Processing Unit (CPU)_ executes instructions as specific patterns of bits. These instructions must follow strict architectural specifications and are known as _machine language_.
### Programming Languages
- **Assembly Language:** A more readable, human-friendly version of machine language, though it remains tied to specific CPU architectures and is considered _low-level_.
- **High-Level Languages**: Languages like _C, C++, Java,_ and _Python_ offer abstraction from machine architecture, making them easier to read and write.
### Execution Models
- **Compiled Languages** (e.g., _C_): A compiler transforms source code into machine-executable files.
- **Interpreted Languages** (e.g., _Python_): An interpreter analyzes and executes the code directly without creating a separate executable file.
### About the C Language
Created by _Dennis Ritchie_ around 1970, _C_ is a high-level language that still provides significant low-level control. It serves as the foundation for many modern languages, making it an excellent choice for learning about computer architecture.
