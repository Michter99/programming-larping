### Computer Memory and Execution:
- **Primary vs. Secondary Storage:** Programs are stored permanently on the _hard disk drive_ (secondary storage) but are transferred to the _Random Access Memory_ (RAM, or main memory) for execution because RAM access is significantly faster.
- **CPU Execution:** The _Central Processing Unit_ (CPU) fetches instructions from the RAM sequentially. While it has limited onboard memory for immediate tasks, it relies on the RAM for storing program instructions and data.
- **The Operating System:** Acts as the "orchestrator" that manages resource sharing between multiple running programs, including allocation of CPU time and RAM.
### Getting Started with C:
- **Language Analogy:** Learning _C_ is compared to learning a natural language like _English_. It requires mastering the **character set** (alphabet, digits, and special characters), **constants**, **variables**, and **keywords** (e.g., `int`, `long`, `while`).
- **Program Structure:** Once the basic elements are understood, they are organized into **statements** and structures to form a complete program.
- **Computational Logic:** Beyond just knowing the syntax of a language, the most critical skill for a programmer is developing the **computational logic** necessary to solve problems.
